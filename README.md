A collection of beginner‑friendly Python projects to showcase coding practice, problem‑solving, and fundamentals.  
Each project is organized in its own folder with clean code and documentation.

---

## 📂 Projects

- [🔢 Number Guessing Game](./number_guessing)  
  A console game where the user guesses a randomly generated number with feedback (too high/too low) until correct.

- [✂️ Rock-Paper-Scissors](./rock_paper_scissors)  
  Classic user vs computer game with randomized choices, replay option, and clear win/lose/tie messages.

- [⭕ Tic-Tac-Toe](./tic_tac_toe)  
  A simple implementation of Tic‑Tac‑Toe in Python, demonstrating loops, conditionals, and game logic.

---

## 🎯 Purpose

This repository demonstrates:
- Python basics (input handling, loops, conditionals)
- Randomization with the `random` module
- Game logic and user interaction
- Clear documentation and Git version control discipline
